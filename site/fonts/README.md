# Fonts

## SprayME (`sprayme.woff`)

The menu's font on wide screens ([ADR-007](../../docs/adr/007-left-menu-in-sprayme.md)).

- **By** Michał “Neoqueto” Nowak, 2012, built with FontStruct: <https://fontstruct.com/fontstructions/show/718516>
- **Licence:** Creative Commons Attribution-ShareAlike 3.0, <https://creativecommons.org/licenses/by-sa/3.0/>. Anyone may use it for anything with a credit, and a changed version must carry the same licence. The site's footer gives the credit.
- **This copy** is the WOFF file the old site's theme served, unchanged.
- **It covers letters and digits only,** with no accents, dashes or curly quotes. Use it only for words made of plain letters, like the menu's.

The old site's menu font, ALL AGES by KC Fonts, isn't here: its licence allows personal use only.
