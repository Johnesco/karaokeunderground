# Karaoke Underground

The rebuild of [karaokeunderground.com](https://karaokeunderground.com), the site for Karaoke Underground: punk and indie video karaoke in Austin, Texas.

> **Status: discovery.** The live site is still the legacy WordPress install, and nothing in this repo is deployed yet.

## Where things are

- **Work:** [open issues](https://github.com/Johnesco/karaokeunderground/issues). Every change starts as one
- **Decisions:** [`docs/adr/`](docs/adr/README.md). The first, ADR-001, picks the stack
- **The old site:** [`docs/legacy-site/`](docs/legacy-site/audit.md). What it has and does, and every URL the rebuild must redirect
- **Changes:** [`CHANGELOG.md`](CHANGELOG.md)

## Process

This project runs on [sdlc-baseline](https://github.com/Johnesco/sdlc-baseline) (profile `core`): every change starts as a ticket, gets decided before it's built, and is verified by a person before it counts as done.
